How it works

From raw log lines to an explained incident in four steps.

01 · DETECT

Score each block

A classifier flags the block as Normal or Anomaly with a confidence score.

02 · RETRIEVE

Find similar past cases

The closest labeled blocks are pulled from the index to serve as evidence.

03 · EXPLAIN

Write the explanation

A language model explains the verdict using those cases as evidence.

04 · DRAFT

Draft the incident ticket

For a likely anomaly, a ticket can be drafted on demand.
