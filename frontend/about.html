LogSense

Find unusual log blocks and see why, backed by similar past incidents.

LogSense is an AI-powered anomaly detector for HDFS system logs that explains its verdicts using similar past incidents instead of guessing blind.

1

Retrieve

Finds similar past incidents from the historical dataset using vector similarity search.

2

Explain

The AI explains its verdict using those real past cases as evidence, not a blind guess.

3

Draft

If it looks like a real problem, a draft incident ticket is created automatically.

Trained and tested on real HDFS (Hadoop Distributed File System) logs — 575,061 blocks, each labeled Normal or Anomaly from verified historical records.

~85%
Accurate, with similar past incidents
~31%

From a 200-case test run on Oct 28, 2026. Each AI explanation is scored by counting anomaly- vs. normal-leaning keywords in the text — a simple, approximate method, so treat these numbers as an estimate, not a precise measurement.
